# Anomalies (Kuhn)

Anomaly: a problem that cannot be solved within the paradigm; accumulating anomalies lead to a crisis and a new paradigm (Kuhn).

## How to apply (project suggestion)

1. Record results that do not fit expectations.
2. Check that it is not a measurement error.
3. Ask which assumption is broken.
4. Formulate a hypothesis to replace it.
