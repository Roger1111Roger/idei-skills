# Morphological analysis

The problem is broken down into parameters and options, then their combinations are enumerated (Zwicky).

## How to apply (project suggestion)

1. Break the problem down into independent parameters.
2. List the options for each parameter.
3. Build a matrix and go through the combinations.
4. Screen out the unfeasible ones and choose the promising ones.
