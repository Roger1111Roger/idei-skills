# Serendipity

An unexpected event noticed by a person with the right skills: neither pure luck nor pure skill.

## How to apply (project suggestion)

1. Leave a time buffer in the work for deviations.
2. Write down unexpected findings immediately.
3. Return to your notes periodically.
