# Geneplore

Creativity as a two-phase cycle: generating raw “preinventive structures” and exploring them (Finke, Ward, Smith, 1992).

## How to apply (project suggestion)

1. Quickly produce many raw forms without criticism.
2. Look for what can be interpreted and applied in each form.
3. Return to generation if no meaning was found.
