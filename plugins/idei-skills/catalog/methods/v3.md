# Discovery-driven planning

For projects with high uncertainty (McGrath, MacMillan, 1995): a plan is judged by what it teaches, not by how closely it matches the forecast. Funding is released by milestones. The source names the elements but does not explain how to build each document.

## How to apply (project suggestion)

1. Define success, including a “reverse” profit statement: from the required result backward.
2. Compare with the market and competitors.
3. Write down what is required of operations.
4. Keep a register of assumptions and check them.
5. Set checkpoints after which decisions about further funding are made.
