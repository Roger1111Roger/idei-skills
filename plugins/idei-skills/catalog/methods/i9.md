# Reverse brainstorming

Checking a short list of ideas with the question “what could go wrong” (Rawlinson, 1981). Applied to selected ideas, not to the first flow. It takes effort and can discourage people, so a constructive review is needed.

## How to apply (project suggestion)

1. Hold a brainstorm on the question “what could go wrong with this idea”.
2. Find groups of remarks with the same meaning.
3. Turn each group into one positive statement.
4. Repeat and finish with a review so as not to discourage people.
