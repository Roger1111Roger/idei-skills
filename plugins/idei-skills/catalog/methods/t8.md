# Requirements traceability

A table of links between documents, for example “requirement — test case”, helps to check the completeness of coverage.

## How to apply (project suggestion)

1. Number the requirements.
2. For each, write the numbers of the test cases.
3. Find requirements without test cases and test cases without requirements.
