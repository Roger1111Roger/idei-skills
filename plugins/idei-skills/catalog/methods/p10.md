# Abduction

Reasoning that generates explanatory hypotheses (Peirce): from a surprising fact to a hypothesis that would make it expected. In the modern sense, this is inference to the best explanation.

## How to apply (project suggestion)

1. Record the surprising fact.
2. Ask: what would have to be true for this to be expected?
3. Write down at least three explanations.
4. Choose the one that explains better and can be tested.
