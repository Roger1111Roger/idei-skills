# Conceptual blending

Two mental spaces are projected into a blend with a new structure (Fauconnier, Turner, 2002).

## How to apply (project suggestion)

1. Describe two mental spaces.
2. Choose a shared schema and one feature from each.
3. Project them into a blend and run it as a scenario.
4. Assess which new properties have appeared.
