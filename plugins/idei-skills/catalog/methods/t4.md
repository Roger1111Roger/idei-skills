# User stories

A requirement as a short story in the template “As a <role>, I can <action>, so that <benefit>” (Kent Beck, XP; Connextra template).

## How to apply (project suggestion)

1. Write: “As a <role>, I can <action>, so that <benefit>.” The “so that” part is optional.
2. Add acceptance criteria: what the story must do to be accepted.
3. Split stories that are too large.
