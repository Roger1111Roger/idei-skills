# Strong inference (Platt)

A cycle of four steps: alternative hypotheses, a crucial experiment, a clean result, repetition for the remaining ones (Platt, 1964).

## How to apply (project suggestion)

1. Write out alternative hypotheses.
2. Devise a crucial experiment: each outcome excludes at least one hypothesis.
3. Run the experiment so that the result is clean.
4. Repeat with sub-hypotheses for the remaining ones.
