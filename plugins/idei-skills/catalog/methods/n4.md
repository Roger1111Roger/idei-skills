# Evidence gap maps

The map shows where research exists and where it does not.

## How to apply (project suggestion)

1. Define the field and the interventions.
2. Systematically find the studies.
3. Place them in an “intervention by outcome” matrix.
4. Treat empty cells as candidate questions.
