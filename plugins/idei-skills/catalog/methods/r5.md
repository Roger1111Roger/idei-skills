# Wizard of Oz

The user works with a “system” behind which a human acts manually. The idea is tested without development (Kelley, 1984).

## How to apply (project suggestion)

1. Describe what the user will see and do.
2. One person manually imitates the work of the system.
3. Observe and record the user's behavior.
4. Decide whether it is worth automating.
