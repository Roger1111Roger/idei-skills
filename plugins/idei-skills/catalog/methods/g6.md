# Focal object method

The attributes of a random object are applied to those of the original object to obtain unusual combinations.

## How to apply (project suggestion)

1. Choose the original object and a random object.
2. Write down the attributes of the random object.
3. Apply each attribute to the original object.
4. Assess the unusual combinations.
