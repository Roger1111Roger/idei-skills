# TRIZ

Theory of Inventive Problem Solving: laws of development of technical systems and standard techniques for resolving contradictions (Altshuller).

## How to apply (project suggestion)

1. Describe the problem and the ideal final result.
2. State the technical contradiction: improving one thing worsens another.
3. Find standard techniques for resolving the contradiction.
4. Check the solution for new contradictions.
