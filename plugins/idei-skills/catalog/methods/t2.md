# Kano model

Features are divided into must-be, linear and attractive (Kano, 1984).

## How to apply (project suggestion)

1. Write out the idea's features.
2. For each, ask: “how would you feel if it is present” and “if it is absent”.
3. Assign the feature to a category based on the answers.
4. Include the must-be features in the spec first.
