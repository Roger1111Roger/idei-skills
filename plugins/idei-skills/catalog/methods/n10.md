# Counterfactual thinking

Imagine an alternative to what has already happened. “Upward” versions (how it could have been better) show what to change in the future.

## How to apply (project suggestion)

1. Take an event or a decision.
2. Imagine how it could have been better: add an action that did not happen, or remove something that did.
3. Describe the consequences.
4. Turn the differences into a testable hypothesis.
