# Backcasting

A normative approach: first describe the desired future, then determine the steps from it back to the present (Robinson).

## How to apply (project suggestion)

1. Describe the desired future.
2. Determine what must happen before it.
3. Build the path back to the present.
4. Single out the nearest steps.
