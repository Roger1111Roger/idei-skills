# MoSCoW

Prioritization of requirements: must, should, could, won't have this time (Dai Clegg, 1994; widely used in DSDM).

## How to apply (project suggestion)

1. Write out the requirements.
2. Sort them into four groups.
3. “Must” is critical for the current delivery: without any one of them it is considered a failure.
4. Check that all the “musts” really fit in the time frame.
