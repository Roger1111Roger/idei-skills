# Technology readiness levels (TRL)

Nine levels from an idea to a technology proven in operation (NASA).

## How to apply (project suggestion)

1. Describe the idea's technology.
2. Use the scale to determine which level is already proven.
3. Compare with the required level.
4. Turn the gap into check tasks.
