# Divergent thinking

Creativity is measured by answers to an open-ended task: fluency (how many), flexibility (how varied), originality (how unusual), elaboration (Guilford).

## How to apply (project suggestion)

1. Set a limit: 20 options in 5 minutes.
2. Group the options by category: flexibility equals the number of categories.
3. Mark rare options as original and develop the best ones.
4. For practice, use a task about unusual uses of an object.
