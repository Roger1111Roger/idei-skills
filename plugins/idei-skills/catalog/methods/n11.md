# Thought experiments

An imagined situation in which an operation is carried out mentally and the consequences are examined. Destructive experiments reveal contradictions in a theory; constructive ones help understanding.

## How to apply (project suggestion)

1. Build an idealized scenario.
2. Apply a theory or assumption to it.
3. Find a contradiction or an unexpected conclusion.
4. Check the conclusion against real observation.
