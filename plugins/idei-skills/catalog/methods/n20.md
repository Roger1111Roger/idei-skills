# Preregistration

Hypotheses, design and analysis plan are publicly recorded before data collection; this separates hypothesis testing from exploratory analysis.

## How to apply (project suggestion)

1. Describe the hypotheses, design and analysis plan before collecting data.
2. Register the plan with a timestamp.
3. Carry it out according to the plan.
4. Mark deviations explicitly and separate confirmatory and exploratory analyses.
