# Pre-mortem

The group imagines that the project has already failed and explains the reasons (Klein, 2007).

## How to apply (project suggestion)

1. Tell the group: “Imagine that a year from now the project has failed.”
2. Everyone silently writes down the reasons.
3. Collect the reasons and group them.
4. For the main reasons, add assumptions or measures to the check.
