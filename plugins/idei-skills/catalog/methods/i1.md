# Creative Problem Solving

A structured method: six stages, in each of which options are first generated and then narrowed (Parnes, 1950s; Isaksen, Treffinger). Stages 1–5 are used here; the sixth (implementation plan) is outside the project's scope.

## How to apply (project suggestion)

1. Mess-finding: write out what is worth solving and choose the main item.
2. Data-finding: gather facts (who, what, where, when, why, how).
3. Problem-finding: reformulate into a broad statement suitable for ideas.
4. Idea-finding: come up with as many as possible, without evaluating.
5. Solution-finding: set criteria, compare the strong ideas and choose the best.
