# Problem finding

The value of research depends on how well the problem is found and formulated (Getzels, Csikszentmihalyi, 1976).

## How to apply (project suggestion)

1. Write down the original problem statement.
2. Reformulate it in at least three ways.
3. Compare which formulation opens up more paths.
4. Choose a formulation and record it.
