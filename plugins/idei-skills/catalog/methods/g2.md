# ARIZ

Algorithm of Inventive Problem Solving: a step-by-step conversion of a vague problem into a physical contradiction.

## How to apply (project suggestion)

1. State the mini-problem.
2. Identify the conflicting elements and the ideal result.
3. Move to the physical contradiction.
4. Find a way to resolve it and check it.
