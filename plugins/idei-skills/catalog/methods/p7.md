# Structure mapping

Analogy transfers a system of relations between objects, not surface features (Gentner, 1983).

## How to apply (project suggestion)

1. Describe the problem through relations between elements, without details.
2. Find a field where such a relation is already solved.
3. Transfer the system of relations, not the outward appearance.
4. Check where the transfer breaks down.
