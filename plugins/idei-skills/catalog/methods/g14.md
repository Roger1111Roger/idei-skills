# QFD and FCA

Quality function deployment and functional cost analysis: translating requirements into characteristics and finding cheap ways to deliver a function.

## How to apply (project suggestion)

1. Write out user requirements and rate their importance.
2. Translate them into technical characteristics and link them to the requirements (9 / 3 / 1).
3. Describe functions as “verb + noun” pairs and build a FAST diagram using the “how / why” logic.
4. For each function, look for another way to perform it.
