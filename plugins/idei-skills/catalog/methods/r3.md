# Fermi estimation

A rough estimate of a quantity by parts, to land within an order of magnitude.

## How to apply (project suggestion)

1. Break the question into estimable parts.
2. Estimate each one roughly.
3. Combine and obtain the estimate.
4. If desired, set lower and upper bounds.
5. Compare with the threshold from the success criteria.
