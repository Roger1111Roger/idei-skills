# Mind maps

A branching diagram radiating from a central topic (Buzan).

## How to apply (project suggestion)

1. Write the central topic as an image in the center.
2. Draw branches from it with the main subtopics.
3. On each branch, put one key word or image.
4. Use colors and look for links between branches.
