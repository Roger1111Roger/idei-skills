# Provocation and movement (PO)

A deliberately false statement about what is taken as given serves as a starting point for ideas (de Bono, 1992). The source notes: it does not always give useful ideas and works better in a close-knit group.

## How to apply (project suggestion)

1. Make a provocation: “houses have no roofs”.
2. Do not evaluate it, accept it as it is.
3. Movement: work through the consequences, benefits, circumstances in which it makes sense, and the principles needed for it to work.
4. Return to the task with the ideas obtained.
