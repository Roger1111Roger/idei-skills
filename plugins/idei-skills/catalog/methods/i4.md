# Speculative design

Assumptions about a possible future, to provoke discussion (Dunne, Raby). This is not a feasibility check; critics argue that without working objects it is not design. It is suitable as a source of ideas that then go into the check steps.

## How to apply (project suggestion)

1. Take a technology that is only emerging.
2. Build a “what if” scenario together with the context in which it is used.
3. Present it as a description or an object that provokes debate.
4. From the reaction, choose ideas to check for feasibility.
