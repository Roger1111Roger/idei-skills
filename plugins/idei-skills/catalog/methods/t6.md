# Equivalence classes and boundaries

Input data is divided into classes with the same behavior, and a class representative and values at the boundaries are tested (ISTQB).

## How to apply (project suggestion)

1. Identify valid and invalid ranges.
2. Take one value from each class.
3. Add values at the boundaries and next to them.
4. Write the expected result for each.
