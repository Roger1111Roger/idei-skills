# Given / When / Then

A scenario in three parts: the state before, the behavior, the expected result (Terhorst-North, Matts; BDD). The same format suits acceptance criteria.

## How to apply (project suggestion)

1. Given: the initial state.
2. When: the action.
3. Then: the observable result.
4. One example tests one rule.
