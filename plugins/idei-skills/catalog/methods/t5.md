# Use cases

A description of the primary actor's goal: the main success path and extensions for failures (Cockburn template).

## How to apply (project suggestion)

1. Name the primary actor, the goal and the trigger event.
2. Write the preconditions and the result on success.
3. Describe the main success path in numbered steps.
4. Add extensions (3a: step 3 went wrong) and the failure condition.
5. Each path will become the basis for a test case.
