# Extenics (Cai Wen)

A Chinese theory (Cai Wen, 1983) on solving incompatible problems: an object is described by a triple “object, characteristic, value” and this is transformed to remove the contradiction. The source gives no general algorithm; the steps below retell the description and a worked example (choosing a hydro turbine), not a ready-made procedure.

## How to apply (project suggestion)

1. Describe the object as a triple: object, characteristic, value.
2. Find the incompatibility: which requirements do not agree at the current values.
3. Apply a transformation: extend, branch out or correlate characteristics and values.
4. Change values level by level within the constraints until the requirements agree.
