# Design thinking

An iterative cycle: empathy, problem definition, ideation, prototype, test (Stanford d.school). The stages are not strictly sequential..

## How to apply (project suggestion)

1. Study users: interviews, observation.
2. State the problem as a question.
3. Generate ideas and choose a few.
4. Make a cheap prototype and test it with people.
5. Return to the appropriate step based on the result.
