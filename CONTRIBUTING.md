# Contributing

The repository is read-only for others: there is no direct write access. Suggestions are welcome through issues and pull requests.

The main rule of the project: **every method is backed by a source that the author of the change actually read.** No guessing and no workarounds.

1. Edit methods in the map `map/idei.html` (the `CL`, `MAP`, `APR`, `STP`, `EXT` arrays at the start of the script), not in `catalog/`. The catalog is regenerated by the script.
2. A new or changed description needs a link to the page it was checked against. If the page was not read, do not add a link: the catalog will then honestly mark it "not checked against a primary source".
3. If sources disagree, write the disagreement into the card text instead of picking the convenient version.
4. After a change run `node tools/extract_catalog.js`, then `claude plugin validate ./plugins/idei-skills`.
5. Scope: invent an idea, check it, prepare the spec, test cases and prompt. Implementation tools are out of scope.
